# metrl-py

Builds the `metrl` wheel; the native module is `metrl._core`.

- Depends only on `worker` and `common/*`.
- Python owns the event loop (uvloop). Expose async work as `#[pyfunction] async fn`
  (pyo3 `experimental-async`) and run Rust futures on the pyo3-async-runtimes tokio
  runtime. When Python cancels the call, the Rust work must stop; never start a
  separate runtime or block the loop.
- Release the GIL around Rust work that may block.
- Tensors cross as `TensorData` through the buffer protocol. No copies, no pickling.
- Stubs are generated by `maturin develop --generate-stubs` (pyo3 `experimental-inspect`)
  and are not committed. Never hand-edit `_core.pyi`; fix the Rust signature or add a
  `#[pyo3(signature = (...) -> "...")]` annotation instead.
- Rebuild with `just setup` after changing Rust code.
